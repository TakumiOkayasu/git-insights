# GitLens全体を段階的に再現する

2026-09-18の追加要望により、草案の「不足するFile/Line History・CodeLens・Rebaseだけを自作する」という範囲を変更した。Git Insights自身をリポジトリ全体の作業画面にする。

公開画面の情報配置・密度・操作手順を参照し、コードと画面は独自に実装する。GitLensのコード、CSS、画像は製品へ組み込んでいない。

## 第1段階の操作

アクティビティバーのGit Insightsからリポジトリを選ぶか、コマンド「Git Insights: リポジトリグラフを開く」を実行する。ファイルを開いていなくても利用できる。

- 左側の一覧でローカル／リモート／タグを選ぶと、その履歴へ絞り込む。「すべてのブランチ」で戻す。
- 追跡先があるローカルブランチには上矢印がahead、下矢印がbehindを表示する。追跡先の名前はツールチップで確認できる。
- リモート一覧はremote-tracking refsのローカル記録。Fetchボタンで全リモートを取得する。定期的なネットワーク通信は行わない。削除済みリモート参照のpruneは行わない。
- コミットを選択すると詳細と変更ファイルを表示し、ファイル選択でVS Code差分エディタを開く。
- 「比較」で元と先のブランチ／タグを選び、共通祖先の有無を指定する。比較は解決済みSHAに固定する。
- 上部の現在ブランチのボタンからローカルブランチを切り替える。強制切り替えは行わず、Gitが拒否した場合はエラーを表示する。
- 検索は読み込み済みの件名・本文・著者・SHA・参照名を照合し、一致しない行を薄くする。グラフの接続を維持するため行を取り除かない。
- 最初の300件から追加読み込みでき、上限は5,000件。全履歴検索・仮想スクロールは後続段階。

## 設計

`Repository` はsnapshot・inspect・compare・fetchという操作の契約。Gitの出力形式とコマンドは生成境界内に置く。画面通知は別のDTOとして型と実行時検証を持つ。世代番号と選択番号で非同期結果を照合し、古い選択の差分を開かない。比較表示は既存の `Comparison.open()` を再利用する。

グラフは実際のコミットの親SHAからレーンを計算する。描画はCanvas、UIアイコンはMicrosoftのCodiconsを使用する。
